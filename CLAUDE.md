# Claude Code Project Rules

Read these files before changing code:

- `PROJECT.md`
- `TASKS.md`
- `PROGRESS.md`

## Working rules

1. Work on only one task from `TASKS.md` per iteration.
2. Continue an `IN_PROGRESS` task before starting a `TODO` task.
3. Do not invent new requirements or expand scope.
4. Inspect existing code before editing it.
5. Run the verification commands defined in `PROJECT.md`.
6. Mark a task `DONE` only after its acceptance criteria pass.
7. Record each iteration in `PROGRESS.md`.
8. When blocked, mark the task `BLOCKED` and record the exact reason.

## Safety

- Never read, print, copy, or store credentials or secrets.
- Never push, deploy, change cloud resources, or modify DNS.
- Never run destructive Git or filesystem commands.
- Never disable or weaken tests merely to make them pass.
- Stay inside this repository.
