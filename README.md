# Contra-Inspired Project Overrides

These files are designed to replace the project-specific files in the minimal Claude Code loop-engineering template.

## Replace these files

Copy into the root of the minimal template and overwrite:

- `PROJECT.md`
- `TASKS.md`
- `FIRST_RUN_PROMPT.md`
- `PROGRESS.md`

Keep these generic template files unchanged:

- `CLAUDE.md`
- `.claude/loop.md`
- `.claude/settings.json`
- `ADD_ENHANCEMENT_PROMPT.md`

## Start

1. Initialize Git and commit the planning files.
2. Start Claude Code in the repository root.
3. Paste the content of `FIRST_RUN_PROMPT.md` into Claude Code.
4. Review the first iteration and run the generated project locally.
5. When satisfied, start the recurring task with `/loop 6h`.

The project is intentionally defined as an original run-and-gun game inspired by classic arcade design. It must not use copied commercial game assets or extracted ROM content.
